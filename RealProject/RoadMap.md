# 📊 ML Learning Plan - Time Series & Finance

**Objective** : Build concrete projects with financial data  
**Level** : Beginner → Intermediate  
**Format** : Theory + Code explained line by line + Projects

---

## 🎯 Complete Roadmap

### Phase 1: Foundations (1-2 weeks)
1. **[01] Preprocessing & Feature Engineering** - Prepare data correctly
2. **[02] Validation & Evaluation** - Measure if it really works
3. **[03] Train/Test Split & Cross-Validation** - Avoid overfitting

### Phase 2: Classic Algorithms (2-3 weeks)
4. **[04] Decision Trees & Random Forest** - Understand feature importance
5. **[05] Linear Regression & Logistic Regression** - Statistical basics
6. **[06] SVM & KNN** - Other approaches
7. **[07] Ensemble Methods** - Combine multiple models

### Phase 3: Time Series (2-3 weeks)
8. **[08] Time Series Fundamentals** - Trend, Seasonality, Stationarity
9. **[09] ARIMA & Exponential Smoothing** - Classic models
10. **[10] Prophet (Facebook)** - Simplified forecasting
11. **[11] LSTM & RNN** - Deep Learning for sequences

### Phase 4: Finance Specialization (2-3 weeks)
12. **[12] Real Financial Data** - Fetch, clean, calculate indicators
13. **[13] Price Prediction** - Concrete project
14. **[14] Trend Detection & Trading Signals** - Advanced project
15. **[15] Backtesting** - Test strategy on historical data

### Phase 5: Concrete Projects (3-4 weeks)
- **Project 1** : Predict stock price (LSTM)
- **Project 2** : Create ML-based trading indicator
- **Project 3** : Algorithm comparison on real data

For **each topic**, you'll get:

1. **📄 .md file** with :
   - Clear theoretical explanation
   - Practical use cases
   - Pitfalls to avoid

2. **💻 Complete code** with :
   - Line-by-line comments
   - Explanation of the "why"
   - Example on simple data
   - Example on real data (stocks)

3. **🎯 Mini-exercise** to do yourself

4. **🔗 Link to next chapter**
